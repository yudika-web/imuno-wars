# v0.9 — Start Screen, Menu & Music

- Memuat: progress sesuai jumlah gambar yang selesai, tombol start aktif saat siap.
- Splash baru dari gambar pengguna, utuh tanpa crop, tombol Sentuh untuk Mulai.
- Menu utama dengan artwork baru, tombol game, animasi gelembung, layout responsif.
- Tiga MP3 pengguna untuk menu, battle, dan boss; satu pemutar, loop, tidak autoplay sebelum sentuhan.
- Pengaturan musik dan SFX terpisah dari menu utama/Pause; slider, mute, penyimpanan, dan tes SFX.
- Pause/tab tersembunyi menghentikan musik. ESC di pengaturan menutup dialog tanpa melanjutkan battle.
- Perubahan mekanik inti: tidak ada. Kartu pasukan atas, eritrosit oksigen, dan SFX dipertahankan.
- 74 pemeriksaan otomatis lulus; tiga MP3 lolos decode penuh. Belum diuji tampilan atau playback di browser/perangkat nyata.
